# Knowledge Media Factory

This directory is the executable contract layer for the AI knowledge-media system.

Canonical strategy lives in:
- `hwangje-vault/직장/콘텐츠/지식 미디어/_INDEX.md`
- `hwangje-vault/직장/콘텐츠/지식 미디어/제작_운영시스템.md`

Pipeline:

`00 orchestrator -> 01 radar -> 02 evidence -> 03 editorial -> 04 script -> 05 visual_design -> 06 production -> 07 qa -> 08 publish -> 09 performance -> 10 learning -> 11 longform_gate -> 00`

Execution split:

- 00-05: ChatGPT orchestration + current web/YouTube/connected research evidence.
- 06: JEONG/GitHub production adapters where deterministic assembly is possible.
- 07: machine QA + editorial QA. Fact/source/originality/channel/watchability/rights gates remain explicit.
- 08: connected publishing path. Publish is complete only after platform readback/proof.
- 09-10: current performance retrieval and learned cause tags.
- 11: repeated winner clusters may graduate to long-form; one viral Short is not enough.

The KR and Global editions share factual Evidence Packs, not scripts. Localization is independent editorial work, not translation.

No timer or publishing cadence is invented here. Quality gates decide whether a piece is publishable; a channel is never fed just to satisfy quota.
