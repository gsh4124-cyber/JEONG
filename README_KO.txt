JEONG Life OS v5.2

수정 사항
- localhost:3000 첫 화면을 없애고 곧바로 /dashboard로 이동
- 로그인 상태의 사용자가 불필요한 소개 페이지를 다시 보지 않음
- 월간 캘린더를 화면 높이에 맞춰 6주 전체 표시
- 28일, 30일, 31일이 아래로 잘리지 않도록 행 높이 자동 계산
- 데스크톱에서는 세로 스크롤 없이 한 달 전체 확인
- 낮은 해상도에서는 헤더와 일정 글자를 자동 축소
- 태블릿·휴대폰에서는 찌그러뜨리지 않고 가로 스크롤로 월간 형태 유지

업데이트
1. 실행 중인 JEONG 창을 종료합니다.
2. 기존 폴더에 압축 내용을 덮어씁니다.
3. .env.local은 유지합니다.
4. .next 폴더를 삭제합니다.
5. JEONG-RUN.cmd를 실행합니다.
6. 화면이 그대로면 Ctrl+Shift+R을 누릅니다.
