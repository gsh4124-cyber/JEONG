JEONG Life OS v8.1 — Premium OS UI Patch

이번 압축은 기존 AI비서_정 프로젝트 위에 덮어쓰는 패치입니다.

변경 내용
- 화면을 절반 크기로 줄여도 사이드바가 찌그러지지 않도록 반응형 구조 재설계
- 중간 폭에서는 88px 아이콘 레일로 자동 전환
- 모바일에서는 상단 가로 내비게이션으로 자동 전환
- 헤더의 시간·날씨·검색 영역이 좁은 화면에서 자연스럽게 줄바꿈
- 밤 아이콘을 얇은 초승달 문자 대신 입체감 있는 둥근 달로 변경
- 다크모드 배경·사이드바·카드에 깊이감과 계층 추가
- PROJECT JEONG 로고와 메뉴 아이콘을 차분한 다크 톤으로 조정
- 기존 일정·할 일·프로젝트·사람·기록·AI 기능 유지

적용 방법
1. JEONG 실행 창을 종료합니다.
2. 이 ZIP의 내용물을 기존 AI비서_정 폴더에 그대로 복사합니다.
3. 같은 이름의 파일이 있다고 나오면 '대상 파일 바꾸기'를 선택합니다.
4. .env.local과 .git은 이 압축에 없으므로 기존 파일이 그대로 유지됩니다.
5. 기존 .next 폴더를 삭제합니다.
6. JEONG-CHECK.cmd를 실행합니다.
7. 검사 성공 후 JEONG-RUN.cmd를 실행합니다.
