JEONG Life OS v6.0 — Structure Cleanup

이번 버전은 기능을 더 추가하지 않고 메뉴와 사용 흐름을 정리했습니다.

변경
- 기본 메뉴를 오늘 / 일정 / 운영 / 기록 / 분석 / AI / 설정으로 축소
- 오늘 화면에서 지난 날짜를 선택해 하루 기록으로 이동
- 별도 하루 페이지 메뉴 제거
- 활동·노트·리뷰·타임라인을 '전체 기록' 화면으로 통합
- 사람 메뉴를 관계 중심 표현으로 정리
- 대시보드를 분석으로 변경
- 챕터와 전체 타임라인은 설정의 고급 기능으로 이동
- 황제노트 표현을 범용적인 '나의 노트'로 변경
- ChatGPT 전용 표현을 외부 AI 연결로 변경
- 기존 세부 기능과 데이터는 삭제하지 않음
