# JEONG UI 실사용 전 점검 기준

- 이메일과 로그아웃은 본문에 직접 노출하지 않는다.
- 날짜·시각·날씨는 상단에서 한눈에 읽힌다.
- 숫자보다 다음 일정과 다음 행동을 먼저 보여준다.
- 새 항목 생성에 브라우저 prompt를 사용하지 않는다.
- 주요 행동은 골드, 보조 행동은 중립, 삭제는 빨강으로 통일한다.
- 설명 없는 숫자를 노출하지 않는다.
- 상세 옵션은 접고 펼치는 구조를 우선한다.
- 1440 / 1024 / 768 / 430px 화면에서 글자와 버튼이 겹치지 않는다.
- 빈 화면도 실패처럼 보이지 않고 다음 행동을 안내한다.
