# JEONG Design System

## 원칙
1. 한눈에 이해되어야 한다.
2. 누르면 펼쳐지고, 닫으면 핵심만 남아야 한다.
3. 색은 보조 정보이며 실제 색과 이름을 함께 보여준다.
4. 주요 행동은 골드, 일반 행동은 중립, 삭제는 빨강으로 구분한다.
5. 설명 없는 숫자를 화면에 노출하지 않는다.
6. 버튼 글자는 줄바꿈되지 않아야 한다.
7. 입력창 높이, 카드 모서리, 여백을 화면 전체에서 통일한다.
8. 기능을 나열하지 않고 관련 정보끼리 묶는다.

## 기본 규격
- 입력창 최소 높이: 44~48px
- 버튼 최소 높이: 40~44px
- 카드 모서리: 12~18px
- 카드 안쪽 여백: 16~24px
- 화면 요소 사이 간격: 8 / 12 / 16 / 24px
- Primary: Gold
- Secondary: Neutral
- Danger: Red outline or red text

## 펼침형 UI
- 세부 설정이 많은 색상, 중간 목표, 연결 항목, 메모는 접고 펼치는 구조를 우선한다.
- 닫힌 상태에서는 이름, 상태, 진행률처럼 판단에 필요한 핵심만 보여준다.
