# JEONG UX Completion Checklist

- 모든 버튼은 동작을 이름으로 설명한다.
- 저장 후 성공 여부가 보인다.
- 같은 정보가 한 화면에 중복 표시되지 않는다.
- 상세 화면에는 원래 화면으로 돌아가는 버튼이 있다.
- 캘린더는 한눈에 보기와 읽기 쉬운 여백을 함께 유지한다.
- 주요 버튼은 짙은 골드와 흰 글씨, 보조 버튼은 밝은 배경과 차콜 글씨를 사용한다.
- 버튼 글씨는 줄바꿈되거나 사라지지 않는다.
- 빈 화면은 다음 행동을 안내한다.
- 모바일과 노트북 폭에서도 주요 버튼이 화면 밖으로 밀리지 않는다.
